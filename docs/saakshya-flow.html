PROVEN

L3. Issuer's own signature verifies. Cryptographic proof, nothing more to check.

CONFIRMED

L2. Every claim matches the issuer's register. Forensics clean.

PLAUSIBLE

L1. Looks clean but no register exists. We never say verified here.

REJECTED

L0. Tamper evidence or register contradiction. Goes to an officer.

03

Audit: five forensic signal families

Real tampering touches 0.27–4.17% of pixels (DocForge-Bench 2026). One signal with one threshold misses it, so five independent signals are fused.

Signal (weight)Tech / algorithmWhy thisCause → effect
ELA (0.30)Error Level Analysis. Re-encode as JPEG q=90, take absolute pixel difference. Compare 32 px blocks against the document's own median and MAD.A pasted region was compressed a different number of times than its surroundings, so it re-compresses differently. Median/MAD adapts per document instead of a fixed threshold.cause patch pasted over CGPAeffect blocks there deviate, score rises, contour box drawn, heatmap glows on that spot
Noise residual (0.20)Subtract a median-filtered copy to isolate noise. Standard deviation per 16 px block on flat areas.Every camera or scanner leaves a uniform noise floor. A foreign patch carries a different one.cause patch from another source or re-saveeffect flat blocks with outlier noise are counted into the score
Copy-move (0.20)ORB keypoints and descriptors, brute-force Hamming self-match, cluster matches sharing one offset > 20 px.Forgers clone seals, photos and signatures inside the same page. Identical descriptors at a constant offset reveal it. ORB is free and fast.cause seal duplicatedeffect dense cluster at one offset, score rises. Repeated glyphs on one text line are ignored on purpose
Metadata / PDF structure (0.15)pypdf: count of xref sections (incremental updates), Producer string, ModDate vs CreationDate. Pillow: EXIF Software tag.Editing tools leave file-level traces that pixel edits cannot hide. Immune to AI-generated pixels.cause Producer = Photoshop / Canva / ilovepdf, or multiple xrefseffect score rises even if the image looks perfect
Template / font (0.15)Coefficient of variation of OCR box heights per line cluster; issuer keyword expected in header region.Inserted text rarely matches the form's exact font size and baseline.cause one value set in a different sizeeffect height variance spikes on that line
Fusion
tamper = 0.30·ELA + 0.20·noise + 0.20·copy
       + 0.15·meta + 0.15·template        (0 … 1)

Weighted average today. Roadmap: XGBoost on the five scores, calibrated per issuer with conformal prediction for the human-review band.

06

Anchor (the blockchain part)

Prove the verdict existed at this time and has not been changed. Nothing personal goes on chain.

StepTech / algorithmWhy thisCause → effect
Salted leafleaf = SHA-256(salt ‖ content_hash ‖ verdict), salt = 16 random bytes kept off chain.Without a salt, anyone who knows a student's details could hash them and confirm from the ledger that the student was checked.cause salt deleted (erasure request)effect leaf still valid on chain but refers to nobody. DPDP-compliant
Merkle treePairwise SHA-256 up to one root (RFC 9162 style, last leaf duplicated when odd). Inclusion proof = sibling hashes with left/right position.One root commits to any number of verdicts. A verifier checks one verdict with log₂(n) hashes and sees no other record.cause 10,000 verdicts in a batcheffect 1 ledger write, about 14 hashes per proof
Hash chainblock_hash = SHA-256(index ‖ time ‖ prev_hash ‖ merkle_root). Demo: SQLite, single node. Target: Hyperledger Fabric on MeitY Vishvasya.Each block commits to the one before. History cannot be rewritten without recomputing everything after it.cause one old verdict editedeffect its root changes, that block hash changes, every later block breaks. "Verify chain integrity" reports the first broken index
Rejections tooL0 verdicts are anchored exactly like approvals.A rejection is the record most likely to be disputed or quietly deleted.cause forger retries with tweakseffect trail of rejections exists and cannot be erased
RevocationAppend SHA-256("REVOKE:" + id) as a new leaf.Append-only. Nothing is deleted, it is contradicted later.cause officer revokeseffect verifier shows "Revoked"
